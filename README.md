# 🐸 Momentum // Anti-Uitstel Task Canvas

> **Wetenschappelijk gefundeerde anti-uitstel webapp gebaseerd op WOOP, Micro-Momentum en de 2-Minuten Regel.**

Live demonstratie: **[https://pbaarn.github.io/momentum/](https://pbaarn.github.io/momentum/)**

---

## ✨ Belangrijkste Functionaliteiten

* ⚡ **Snelle Brain Dump (10s Invoer):** Direct taken zonder weerstand noteren en later verrijken.
* 🧠 **Diepe WOOP Intake:** Wish, Outcome, Obstacle (Dread 1-5 🔥) en Als/Dan implementatie-intenties.
* 🧘‍♂️ **Zen Focus Sprint Modus:** Afleidingsvrije sprint-omgeving met een grote countdown timer en sneltoetsen (`Spatie`, `Enter`/`C`, `R`, `Esc`).
* ⏱️ **2-Minuten Activatie Burst:** Micro-momentum om de initiële statische wrijving te doorbreken, met `+5 min Flow` verlenging.
* 🎵 **Synthetische Sound Engine:** Web Audio effecten zonder externe audio-assets.
* 📦 **Offline & Lokale Opslag:** Directe opslag in LocalStorage inclusief JSON backup/restore functionaliteit.
